# User Stories

## 👨‍⚕️ Doctor
- As a Doctor, I want to view my appointments so that I can manage my schedule.
- As a Doctor, I want to update patient prescriptions so that I can provide treatment.
- As a Doctor, I want to view patient details so that I can understand their medical history.

## 🧑‍🤝‍🧑 Patient
- As a Patient, I want to search for doctors so that I can book an appointment.
- As a Patient, I want to book appointments so that I can consult a doctor.
- As a Patient, I want to view my prescriptions so that I can follow treatment.

## 🛠️ Admin
- As an Admin, I want to add doctors so that the system has available specialists.
- As an Admin, I want to manage users so that the system runs smoothly.
- As an Admin, I want to monitor appointments so that operations are efficient.
